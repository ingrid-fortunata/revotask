# RevoTask User Guide · Draft

Verify these labels and steps against the live app before submission. Link the verified deployment in the root README.

1. Register with a name, an email and a password of 8 to 128 characters. The password needs an uppercase letter, a lowercase letter and a special character such as `!`, `?`, `#` or `%`. Then sign in. The dashboard lists boards you can access.
2. Create a board as its admin. Use the Members control to add a registered teammate by email. Add workflow columns, and flag one empty column as Done if you want completion reporting.
3. Add a card to a column. Open it to edit details, assign a participant and post a comment. You can edit or remove your own comments.
4. Drag a card on desktop or use its **Move** control with keyboard or touch. After moving it, reload to verify the new position. If a move fails, look for feedback and retry after the board refreshes.
5. Search a board by card title. Open My Tasks to see your assignments across accessible boards. Use the notification bell to read your updates.
6. Open board analytics for cards per column, distinct cards completed this UTC week and weekly activity. Open Profile to update your name or email. Sign out from the account menu.
